은/는 と 이/가 — 形の規則と、自然さの規則

初級者の質問でいちばん多いのがこれです。実は2つの別々の規則が混ざっています。片方は機械的、もう片方は「文がどう聞こえるか」の話です。

1. 形の規則（機械的）

直前の単語がパッチム（終声の子音）で終わるなら 은 / 이 / 을、母音で終わるなら 는 / 가 / 를。

単語終わり主題主格目的
가방ㅇ（パッチム）가방은가방이가방을
커피母音커피는커피가커피를
저母音저는제가（不規則）저를

例外は代名詞だけ：저 + 가 → 제가、나 + 가 → 내가、누구 + 가 → 누가。

2. 自然さの規則（은/는 か 이/가 か）

  • 은/는（主題）：「〜については」。自分や既知の人が何をするかを述べるとき。저는 커피를 마셔요.
  • 이/가（主格）：描写・新情報・存在。김치가 맛있어요. 고양이가 집에 있어요.
  • 入れ替えても文法的には正しいことが多いですが、ニュアンスが変わります。김치는 맛있어요 は「キムチは（他はともかく）おいしい」という対比に聞こえます。

3. 을/를・에・에서

  • 을/를：動作の対象。책을 읽어요.
  • 에：行き先、または存在する場所。학교에 가요. 집에 있어요.
  • 에서：動作が行われる場所。카페에서 커피를 마셔요. 서울에서 살아요.

覚え方：「行く・いる」なら 에、「そこで何かをする」なら 에서。

은/는 vs 이/가 — the form rule and the naturalness rule

This is the number-one beginner question, and the reason it feels impossible is that two separate rules are tangled together. One is mechanical. The other is about how the sentence sounds.

1. The form rule (mechanical)

If the word before the particle ends in a consonant (a 받침), use 은 / 이 / 을. If it ends in a vowel, use 는 / 가 / 를. That is all.

WordEnds inTopicSubjectObject
가방 (bag)ㅇ (consonant)가방은가방이가방을
커피 (coffee)vowel커피는커피가커피를
저 (I)vowel저는제가 (irregular)저를

The only exceptions are pronouns: 저 + 가 → 제가, 나 + 가 → 내가, 누구 + 가 → 누가.

2. The naturalness rule (은/는 or 이/가?)

  • 은/는 (topic) — “as for X”. Use it when you say what you or a known person does. 저는 커피를 마셔요. (I drink coffee.)
  • 이/가 (subject) — describing, new information, existence. 김치가 맛있어요. (Kimchi is delicious.) 고양이가 집에 있어요. (The cat is at home.)
  • Swapping them is usually still grammatical, but the meaning shifts. 김치는 맛있어요 sounds like “kimchi, unlike the other dishes, is delicious”. 제가 커피를 마셔요 sounds like “I am the one drinking the coffee”.

3. 을/를 · 에 · 에서

  • 을/를 — the thing acted on. 책을 읽어요. (I read a book.)
  • 에 — a destination, or where something IS. 학교에 가요. 집에 있어요.
  • 에서 — where an action happens. 카페에서 커피를 마셔요. 서울에서 살아요.

Rule of thumb: going or being somewhere → 에; doing something there → 에서.
