なぜ「ランダムな文」ではないのか

ハングルは1週間で読めるようになります。つまずくのはその先——「単語は分かるのに、은/는 と 이/가 のどちらを付けるのか」「학교에 なのか 학교에서 なのか」「どこでスペースを入れるのか」です。Munjang は検証済みの初級文型 {{ counts.frames }} 種と単語 {{ counts.nouns }} 語だけを組み合わせるので、初級で実際に使える型の中で文を組み立てられます。助詞を選ぶたびに、正しいか・自然か・なぜかをその場で説明します。

Why this is not a random sentence generator

You can read Hangul after a week. The wall comes right after: you know the words, but is it 은/는 or 이/가? 학교에 or 학교에서? Where do the spaces go? Munjang only combines {{ counts.frames }} reviewed beginner frames with {{ counts.nouns }} words, so the sentences you build stay inside patterns a beginner can actually use. Each time you choose a particle it tells you whether it is right, whether it sounds natural, and why.

Print it on manuscript paper and write it by hand

Keep up to five finished sentences and print them on a Korean 원고지 grid — one syllable per square, one empty square per space, the same way the TOPIK writing section is laid out.
